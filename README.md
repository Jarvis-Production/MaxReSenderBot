# MAX → Telegram bridge

Пересылает сообщения из одной группы MAX в тему группы-форума Telegram. Работает от вашего аккаунта MAX через неофициальную библиотеку PyMax. Сообщения из других чатов бот не трогает.

> Библиотека использует внутренний API MAX. Это может нарушать правила сервиса и привести к блокировке аккаунта. Папка `session/` даёт полный доступ к вашему аккаунту MAX: не передавайте её никому.

## Настройка

1. Создайте бота Telegram через @BotFather и добавьте его в группу-форум. Дайте боту право писать в нужную тему.
2. Скопируйте `.env.example` в `.env`. Заполните `MAX_PHONE`, `TG_TOKEN`, `TG_CHAT_ID` и `TG_THREAD_ID`. Поле `MAX_CHAT_ID` пока оставьте пустым.
3. Установите зависимости и запустите бота:

   ```bash
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   .venv\Scripts\python bot.py
   ```

4. При первом запуске бот попросит в консоли код из SMS. Сессия сохранится в папку `session/`, повторный вход не понадобится.
5. После входа бот выведет список ваших чатов в формате `id — название`. Скопируйте id нужной группы в `MAX_CHAT_ID` и перезапустите бота.

## Как узнать ID в Telegram

- `TG_CHAT_ID`: перешлите любое сообщение из группы боту @getidsbot или откройте группу в веб-версии Telegram. ID имеет вид `-100...`.
- `TG_THREAD_ID`: скопируйте ссылку на сообщение в нужной теме. Ссылка имеет вид `t.me/c/xxxx/<ID темы>/<ID сообщения>`.

## Перенос на хостинг

Файлы `.env` и `session/` в репозиторий не попадают: в них токен и доступ к аккаунту. На хостинге задайте те же значения как переменные окружения.

1. Войдите один раз на своём компьютере, чтобы появился `session/session.db`.
2. Достаньте из сессии токен входа:

   ```bash
   python -c "import sqlite3;r=sqlite3.connect('session/session.db').execute('select token,device_id,mt_instance_id from sessions').fetchone();print(f'MAX_TOKEN={r[0]}\nMAX_DEVICE_ID={r[1]}\nMAX_MT_INSTANCE_ID={r[2]}')"
   ```

3. На хостинге задайте переменные `MAX_PHONE`, `MAX_CHAT_ID`, `TG_TOKEN`, `TG_CHAT_ID`, `TG_THREAD_ID`, три строки из шага 2 и `DATA_DIR` (постоянная папка хостинга, например `/app/data`). На сервере бот никогда не запрашивает SMS-код: без токена он пишет ошибку в лог и ждёт.
4. Команда запуска: `python bot.py`.
5. Остановите бота на компьютере, иначе сообщения будут приходить дважды.
